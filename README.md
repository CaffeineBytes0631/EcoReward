EcoReward – Rewarding Green Actions, Building a Greener Future 🌍
EcoReward is a web application designed to motivate people to adopt sustainable habits and protect the environment. Users can register, log in, submit their eco-friendly activities for verification, earn EcoPoints, track their environmental contributions, and redeem points for rewards.

Key Features:
User registration and login
Submit eco-friendly activities as proof
Activity verification system
Earn and track EcoPoints
Redeem rewards using earned points
Track environmental contributions
Leaderboard to encourage participation

Technologies Used:
Frontend: HTML, CSS, JavaScript
Backend: Python Flask
Database: MySQL or SQLite, depending on your implementation

Project Goal: To encourage sustainable living by rewarding people for environmentally responsible actions.
Developed as an innovative sustainability project for hackathons and environmental awareness.
